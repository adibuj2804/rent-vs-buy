Advisor: which option fits your case?

Enter your situation. The network estimates the probability that buying with a mortgage leaves you richer than renting and investing after your holding period.

Read this first: this is an educational model, not financial advice. The network imitates the project’s exact model on simulated scenarios (see below); the answer is only as good as the assumptions you enter. Defaults are the 2006–2025 historical averages from the data. Past averages are not forecasts.

How the network works

Nine inputs → two hidden layers of 64 ReLU units → two outputs (probability that buying wins; expected wealth gap). Trained with Adam on 102,000 simulated scenarios; evaluated on 18,000 unseen ones: 80.0 % accuracy vs 59.4 % baseline, Brier score 0.137, agreement with the exact deterministic model 94.8 %. The wealth-gap output is trained on the noise-free exact result: median error 2.6 % of the price, 90 % of cases within 7 % of the price (≈ 19,604 € on a 280,000 € home). When the probability is below 50 % but the gap is positive, that is not a contradiction: gains from buying in good scenarios can be larger than losses in bad ones. Noise in the realised paths uses historical volatility (house 8.7 %/yr, equity 14.6 %/yr), so the output probability reflects market uncertainty.

Calibration on unseen scenarios: when the network says 70 %, buying wins about 70 % of the time if the points follow the diagonal.

// Forward pass of the trained network (9 inputs -> 64 -> 64 -> 2 outputs)
function predict(w, x) {
  let a = x.map((v, i) => (v - w.mu[i]) / w.sd[i]);           // standardise inputs
  w.layers.forEach((L, k) => {
    const out = L.b.slice();
    for (let j = 0; j < out.length; j++)
      for (let i = 0; i < a.length; i++) out[j] += a[i] * L.W[i][j];
    a = (k < w.layers.length - 1) ? out.map(v => Math.max(0, v)) : out;   // ReLU on hidden layers
  });
  return { pBuyWins: 1 / (1 + Math.exp(-a[0])),                // sigmoid -> probability
           gap: a[1] * w.gapScale };                            // wealth gap, share of price
}
train_nn.py: simulation, labelling and training (numpy)
"""Train the advisor neural network on simulated scenarios labelled by the exact model.

Why simulation: ~20 years of local housing history gives only a handful of independent
buy-vs-rent outcomes - far too few for a network. So we
  1. measure from history the plausible ranges and volatilities of every driver,
  2. draw tens of thousands of scenarios from those ranges,
  3. add historical-size noise to the *realised* paths (the household only knows expectations),
  4. label each scenario with the exact model (src/model.py) -> "did buying win?",
  5. train a small MLP (pure numpy, no ML library) to predict P(buy wins) and the wealth gap.
The weights are exported to JSON and the website runs the same forward pass in JavaScript.
"""
import json, os
import numpy as np
import pandas as pd
import model as M

ROOT = os.path.join(os.path.dirname(__file__), "..")
rng = np.random.default_rng(42)

GAP_SCALE = 1.5   # wealth-gap target is clipped to +/-1.5x the purchase price and divided by this
FEATURES = ["city_SK", "years", "ltv", "gross_yield", "buy_cost", "house_growth",
            "rent_growth", "equity_return", "mortgage_rate"]


# ---- 1. what history says about volatility (for the noise on realised paths) -------------
m = pd.read_csv(os.path.join(ROOT, "data/processed/monthly_2003_2025.csv"), index_col=0)
def annual_sd(series, months=12):
    r = (series.shift(-months) / series - 1).dropna()
    return float(r.std())
SD_HOUSE = np.mean([annual_sd(m["hp_es"]), annual_sd(m["hp_sk"])])
SD_EQ = annual_sd(m["msci_eur_tr"])
SD_RATE = 0.012   # std of Euribor level changes over a decade, rounded (see notebook 02)
print(f"historical annual sd  house={SD_HOUSE:.3f}  equity={SD_EQ:.3f}")


# ---- 2/3/4. scenarios + labels -------------------------------------------------------------
def make(n):
    city = rng.integers(0, 2, n)                     # 0 = Spain/Malaga, 1 = Slovakia/Bratislava
    years = rng.integers(2, 26, n)
    ltv = rng.uniform(0.5, 0.9, n)
    yld = rng.uniform(0.03, 0.07, n)
    buy_cost = np.where(city == 0, rng.uniform(0.055, 0.13, n), rng.uniform(0.003, 0.02, n))
    house_g = rng.uniform(-0.02, 0.08, n)
    rent_g = np.clip(house_g * rng.uniform(0.3, 1.0, n) + rng.uniform(0, 0.02, n), 0, 0.06)
    eq = rng.uniform(0.02, 0.10, n)
    rate = rng.uniform(0.015, 0.07, n)
    X = np.c_[city, years, ltv, yld, buy_cost, house_g, rent_g, eq, rate]

    # realised outcome = expectation + noise that shrinks with horizon (sd/sqrt(years))
    z1, z2 = rng.standard_normal(n), rng.standard_normal(n)
    corr = 0.3
    g_real = house_g + SD_HOUSE / np.sqrt(years) * z1
    e_real = eq + SD_EQ / np.sqrt(years) * (corr * z1 + np.sqrt(1 - corr ** 2) * z2)
    r_real = np.clip(rent_g + 0.5 * (g_real - house_g), 0, None)

    sk = city == 1
    pick = lambda a, b: np.where(sk, b, a)
    P, S = M.SPAIN, M.SLOVAKIA
    args = dict(
        ltv=ltv, buy_cost=buy_cost,
        sell_cost=pick(P.sell_cost, S.sell_cost), upkeep=pick(P.upkeep, S.upkeep),
        gross_yield=yld, term_years=pick(P.term_years, S.term_years).astype(float),
        invest_tax=pick(P.invest_tax, S.invest_tax),
        inv_free_after=pick(0, 12).astype(float),
        home_tax=pick(P.home_gain_tax, S.home_gain_tax),
        home_free_after=pick(0, 60).astype(float),
    )
    adv_noisy = M.simulate_batch(g_real, r_real, e_real, rate, years=years, **args)
    adv_exact = M.simulate_batch(house_g, rent_g, eq, rate, years=years, **args)
    return X, adv_noisy, adv_exact


# ---- 5. tiny MLP in numpy ---------------------------------------------------------------
def init(sizes):
    return [(rng.standard_normal((a, b)) * np.sqrt(2 / a), np.zeros(b)) for a, b in zip(sizes[:-1], sizes[1:])]

def forward(params, X):
    acts = [X]
    for i, (W, b) in enumerate(params):
        z = acts[-1] @ W + b
        acts.append(np.maximum(z, 0) if i < len(params) - 1 else z)
    return acts

def train(Xtr, ytr, ctr, epochs=120, lr=2e-3, batch=512, hidden=(64, 64)):
    params = init([Xtr.shape[1], *hidden, 2])
    m_ = [[np.zeros_like(W), np.zeros_like(b)] for W, b in params]
    v_ = [[np.zeros_like(W), np.zeros_like(b)] for W, b in params]
    t = 0
    for ep in range(epochs):
        order = rng.permutation(len(Xtr))
        for s in range(0, len(Xtr), batch):
            idx = order[s:s + batch]
            x, yc, yr = Xtr[idx], ctr[idx], ytr[idx]
            acts = forward(params, x)
            out = acts[-1]
            p = 1 / (1 + np.exp(-out[:, 0]))
            # loss = BCE(win) + 0.5*MSE(scaled wealth gap)
            d = np.c_[(p - yc) / len(idx), 0.5 * 2 * (out[:, 1] - yr) / len(idx)]
            t += 1
            for i in reversed(range(len(params))):
                W, b = params[i]
                gW, gb = acts[i].T @ d, d.sum(0)
                if i > 0:
                    d = (d @ W.T) * (acts[i] > 0)
                for k, (g_, P_) in enumerate([(gW, 0), (gb, 1)]):
                    mm = m_[i][k] = 0.9 * m_[i][k] + 0.1 * g_
                    vv = v_[i][k] = 0.999 * v_[i][k] + 0.001 * g_ ** 2
                    upd = lr * (mm / (1 - 0.9 ** t)) / (np.sqrt(vv / (1 - 0.999 ** t)) + 1e-8)
                    (W if k == 0 else b)[...] -= upd
        if ep % 10 == 9:
            print(f"  epoch {ep+1}/{epochs}")
    return params


if __name__ == "__main__":
    N = 120_000
    X, adv_n, adv_e = make(N)
    y_win = (adv_n > 0).astype(float)
    y_gap = np.clip(adv_e, -GAP_SCALE, GAP_SCALE) / GAP_SCALE                # regression target: gap under the stated assumptions (no noise)
    mu, sd = X.mean(0), X.std(0) + 1e-9
    Xn = (X - mu) / sd
    cut = int(0.85 * N)
    params = train(Xn[:cut], y_gap[:cut], y_win[:cut])
    out = forward(params, Xn[cut:])[-1]
    p = 1 / (1 + np.exp(-out[:, 0]))
    acc = ((p > 0.5) == (y_win[cut:] > 0.5)).mean()
    brier = ((p - y_win[cut:]) ** 2).mean()
    # how often does the network agree with the *exact expected-value* model?
    agree = ((p > 0.5) == (adv_e[cut:] > 0)).mean()
    gap_err = np.abs(out[:, 1] * GAP_SCALE - np.clip(adv_e[cut:], -GAP_SCALE, GAP_SCALE))
    print(f"gap head: median abs error {np.median(gap_err):.3f} of price, 90th pct {np.percentile(gap_err, 90):.3f}")
    base = max(y_win[cut:].mean(), 1 - y_win[cut:].mean())
    print(f"hold-out accuracy {acc:.3f} (majority baseline {base:.3f}); Brier {brier:.3f}; "
          f"agreement with deterministic exact model {agree:.3f}")
    # calibration table
    bins = np.linspace(0, 1, 11)
    cal = []
    for lo, hi in zip(bins[:-1], bins[1:]):
        k = (p >= lo) & (p < hi + (hi == 1))
        if k.sum() > 50:
            cal.append({"bin": f"{lo:.1f}-{hi:.1f}", "predicted": float(p[k].mean()),
                        "observed": float(y_win[cut:][k].mean()), "n": int(k.sum())})
    os.makedirs(os.path.join(ROOT, "site/model"), exist_ok=True)
    json.dump({
        "features": FEATURES, "gapScale": GAP_SCALE, "mu": mu.tolist(), "sd": sd.tolist(),
        "layers": [{"W": W.round(6).tolist(), "b": b.round(6).tolist()} for W, b in params],
        "metrics": {"holdout_accuracy": float(acc), "majority_baseline": float(base),
                    "brier": float(brier), "gap_mae_median": float(np.median(gap_err)), "gap_mae_p90": float(np.percentile(gap_err, 90)), "agreement_with_exact": float(agree),
                    "n_train": int(cut), "n_test": int(N - cut),
                    "sd_house": SD_HOUSE, "sd_equity": SD_EQ},
        "calibration": cal,
    }, open(os.path.join(ROOT, "site/model/nn_weights.json"), "w"))
    print("saved site/model/nn_weights.json")
model.py: the exact engine that labels the scenarios
"""Buy-with-mortgage vs. rent-and-invest: one engine used by both tiers.

Fairness rule: both households spend the same cash every period. Whoever has the
cheaper housing cost that period invests the difference in the same equity index.
At every horizon h we "liquidate" both households and compare final net wealth:

    buyer  = sale price - selling costs - mortgage balance + buyer's side portfolio (after tax)
    renter = portfolio (after tax)

    advantage = buyer - renter      (> 0  ->  buying wins)

Everything is expressed per 1.0 of purchase price, so results are independent of price level.
"""
from __future__ import annotations
from dataclasses import dataclass, replace
import numpy as np
import pandas as pd


@dataclass(frozen=True)
class Params:
    ltv: float = 0.80            # loan-to-value
    buy_cost: float = 0.10       # purchase taxes + notary/registry/lawyer (share of price)
    sell_cost: float = 0.04      # agent + local capital-gain taxes on sale (share of price)
    upkeep: float = 0.012        # maintenance + property tax + insurance, per year, of current value
    gross_yield: float = 0.05    # first-year rent / price
    term_years: int = 25
    spread: float = 0.0          # variable loans: Euribor + spread (calibrated at origination)
    invest_tax: float = 0.21     # tax on portfolio gains at liquidation
    invest_tax_free_after: int = 0  # periods (years*ppy) after which portfolio gains are tax-free (0 = never)
    home_gain_tax: float = 0.0   # tax on home price gain at sale (main-home relief assumed in Spain)
    home_gain_tax_free_after: int = 0  # periods after which home gain is tax-exempt (SK: 5y)


SPAIN = Params()
SLOVAKIA = Params(
    buy_cost=0.006,          # cadastre fee + lawyer; no transfer tax since 2005
    sell_cost=0.03,          # agent fee
    upkeep=0.0105,           # maintenance ~1% + very low property tax
    gross_yield=0.045,
    term_years=30,
    invest_tax=0.0,          # ETF gains tax-free after >1 year ...
    home_gain_tax=0.19,      # ... home gain taxed at 19% if sold within 5 years
)


def annuity(rate_per_period: float, n: int) -> float:
    """Payment per 1.0 of loan."""
    if abs(rate_per_period) < 1e-12:
        return 1.0 / n
    return rate_per_period / (1 - (1 + rate_per_period) ** -n)


def simulate(price_g, rent_g, eq_r, mort_rate_path, p: Params, ppy: int, horizon: int):
    """Simulate one start date for `horizon` periods.

    price_g, rent_g, eq_r : per-period growth/returns (length >= horizon), decimals
    mort_rate_path        : ANNUAL mortgage rate in each period (constant for fixed loans)
    Returns array adv[1..horizon] of buyer - renter wealth (per 1.0 of price) and break-even info.
    """
    n_total = p.term_years * ppy
    price = 1.0
    rent = p.gross_yield / ppy
    loan = p.ltv * 1.0
    bal = loan
    pay_n_left = n_total
    # initial cash: down payment + purchase costs go to the renter's portfolio
    renter = (1 - p.ltv) + p.buy_cost
    renter_contrib = renter
    buyer_port = 0.0
    buyer_contrib = 0.0
    adv = np.zeros(horizon)
    prices = [1.0]
    for t in range(horizon):
        r_per = mort_rate_path[t] / ppy
        pay = annuity(r_per, pay_n_left) * bal if bal > 1e-12 else 0.0
        interest = bal * r_per
        bal = max(bal - (pay - interest), 0.0)
        pay_n_left = max(pay_n_left - 1, 1)
        buy_out = pay + p.upkeep / ppy * price
        rent_out = rent
        diff = buy_out - rent_out
        # growth of existing portfolios first, then new contribution at period end
        renter *= 1 + eq_r[t]
        buyer_port *= 1 + eq_r[t]
        if diff > 0:               # buying costs more cash -> renter invests the difference
            renter += diff
            renter_contrib += diff
        else:                      # renting costs more cash -> buyer invests the difference
            buyer_port += -diff
            buyer_contrib += -diff
        price *= 1 + price_g[t]
        rent *= 1 + rent_g[t]
        periods = t + 1
        # liquidation values
        tax_free = p.invest_tax_free_after and periods > p.invest_tax_free_after
        tr = 0.0 if tax_free else p.invest_tax
        r_net = renter - tr * max(renter - renter_contrib, 0)
        b_net = buyer_port - tr * max(buyer_port - buyer_contrib, 0)
        home_tax_free = p.home_gain_tax_free_after and periods > p.home_gain_tax_free_after
        hg = 0.0 if home_tax_free else p.home_gain_tax
        gain = max(price - 1.0, 0)
        home_net = price * (1 - p.sell_cost) - hg * gain - bal
        adv[t] = home_net + b_net - r_net
    return adv


def slovakia_flags(p: Params, ppy: int) -> Params:
    """SK: ETF gains tax-free after 1 year; home gain tax-exempt after 5 years."""
    return replace(p, invest_tax_free_after=ppy, home_gain_tax_free_after=5 * ppy)


# ---------------------------------------------------------------- tier 1 (monthly)
def tier1_grid(monthly: pd.DataFrame, city: str, rate_type: str, p: Params | None = None,
               max_years: int = 20, start_from: str | None = None):
    """Back-test every start month. Returns DataFrame rows=start month, cols=horizon in years (1..)."""
    if city == "ES":
        hp, hicp_rent, mir = monthly["hp_es"], monthly["hicp_rent_es"], monthly["mir_es"]
        p = p or SPAIN
        start_from = start_from or "2005-01"
    else:
        hp, hicp_rent, mir = monthly["hp_sk"], monthly["hicp_rent_sk"], monthly["mir_sk"]
        p = slovakia_flags(p or SLOVAKIA, 12)
        start_from = start_from or "2008-01"
    eq = monthly["msci_eur_tr"]
    ph = hp.pct_change().shift(-1)           # growth from t to t+1
    rg = hicp_rent.pct_change().shift(-1)
    er = eq.pct_change().shift(-1)
    idx = monthly.index
    out = {}
    for i, m in enumerate(idx):
        if m < pd.Period(start_from, "M"):
            continue
        H = min(max_years * 12, len(idx) - i - 1)
        if H < 12:
            break
        rate0 = mir.iloc[i] / 100
        if rate_type == "fixed":
            path = np.full(H, rate0)
        else:
            spread = rate0 - monthly["euribor12m"].iloc[i] / 100
            path = np.clip(monthly["euribor12m"].iloc[i:i + H].values / 100 + spread, 0.005, None)
        adv = simulate(ph.iloc[i:i + H].values, rg.iloc[i:i + H].values, er.iloc[i:i + H].values,
                       path, p, 12, H)
        out[m] = {y: adv[y * 12 - 1] for y in range(1, max_years + 1) if y * 12 <= H}
    return pd.DataFrame(out).T


# ---------------------------------------------------------------- tier 2 (annual, JST)
def tier2_grid(jst: pd.DataFrame, iso: str = "ESP", p: Params | None = None,
               start_from: int = 1950, max_years: int = 30, rate_spread: float = 0.015):
    """Annual back-test from `start_from` on JST national data (nominal, local currency)."""
    d = jst[jst.iso == iso].set_index("year").sort_index()
    p = p or SPAIN
    # house price growth: observed price index where available, JST capital-gain series before
    g = d["housing_capgain"]
    ry = d["housing_rent_yd"]            # rent / price (JST)
    rate = (d["ltrate"] / 100 + rate_spread).clip(lower=0.01)
    eq = d["eq_tr"]
    cols = pd.concat([g, ry, rate, eq], axis=1, keys=["g", "ry", "rate", "eq"]).dropna()
    years = cols.index.values
    out = {}
    for i, y in enumerate(years):
        if y < start_from:
            continue
        H = min(max_years, len(years) - i - 1)
        if H < 5:
            break
        # rent grows with house prices times yield drift: rent_t = yield_t * price_t
        P = np.r_[1.0, np.cumprod(1 + cols["g"].values[i + 1:i + H + 1])]   # price at start of year k
        rent_path = cols["ry"].values[i:i + H + 1] * P                       # rent_k = yield_k * price_k
        rg = rent_path[1:] / rent_path[:-1] - 1
        pp = replace(p, gross_yield=cols["ry"].values[i])
        adv = simulate(cols["g"].values[i + 1:i + H + 1], rg, cols["eq"].values[i + 1:i + H + 1],
                       np.full(H, cols["rate"].values[i]), pp, 1, H)
        # deflate to start-year money so decades with high inflation are comparable
        cpi = d["cpi"].reindex(years).values
        out[int(y)] = {h: adv[h - 1] / (cpi[i + h] / cpi[i]) for h in range(1, H + 1)}
    return pd.DataFrame(out).T


def break_even(row: pd.Series):
    """First horizon from which buying stays ahead (None if never)."""
    ok = row.dropna()
    wins = ok > 0
    for h in ok.index:
        if wins.loc[h:].all():
            return h
    return None


# ---------------------------------------------------------------- vectorised engine (for the network)
def simulate_batch(g, rg, eq, rate, ltv, buy_cost, sell_cost, upkeep, gross_yield, term_years,
                   invest_tax, inv_free_after, home_tax, home_free_after, years):
    """Same economics as `simulate`, monthly, constant annual rates, for N scenarios at once.

    All arguments are arrays of shape (N,) (annual decimal rates). `years` is the horizon (N,)
    in whole years; returns advantage (buyer - renter) per 1.0 of price at that horizon.
    """
    N = len(g)
    gm = (1 + g) ** (1 / 12) - 1
    rgm = (1 + rg) ** (1 / 12) - 1
    em = (1 + eq) ** (1 / 12) - 1
    r = rate / 12
    n_left = (term_years * 12).astype(float)
    price = np.ones(N)
    rent = gross_yield / 12
    bal = ltv.copy()
    renter = (1 - ltv) + buy_cost
    renter_c = renter.copy()
    bport = np.zeros(N)
    bport_c = np.zeros(N)
    H = (years * 12).astype(int)
    result = np.zeros(N)
    for t in range(int(H.max())):
        # annuity payment on remaining balance
        pay = np.where(np.abs(r) < 1e-12, 1.0 / n_left, r / (1 - (1 + r) ** (-n_left))) * bal
        interest = bal * r
        bal = np.maximum(bal - (pay - interest), 0)
        n_left = np.maximum(n_left - 1, 1)
        diff = pay + upkeep / 12 * price - rent
        renter = renter * (1 + em)
        bport = bport * (1 + em)
        pos = diff > 0
        renter = renter + np.where(pos, diff, 0)
        renter_c = renter_c + np.where(pos, diff, 0)
        bport = bport + np.where(pos, 0, -diff)
        bport_c = bport_c + np.where(pos, 0, -diff)
        price = price * (1 + gm)
        rent = rent * (1 + rgm)
        done = (H == t + 1)
        if done.any():
            per = t + 1
            tr = np.where((inv_free_after > 0) & (per > inv_free_after), 0.0, invest_tax)
            hg = np.where((home_free_after > 0) & (per > home_free_after), 0.0, home_tax)
            r_net = renter - tr * np.maximum(renter - renter_c, 0)
            b_net = bport - tr * np.maximum(bport - bport_c, 0)
            home_net = price * (1 - sell_cost) - hg * np.maximum(price - 1, 0) - bal
            result = np.where(done, home_net + b_net - r_net, result)
    return result

Limits of the advisor

  • It ignores your personal tax situation beyond the city rules, job risk, and what else you could do with the money.
  • Inputs outside the training ranges (e.g. LTV below 50 % or above 90 %, horizons beyond 25 years) are clamped and flagged.
  • Two decades of local history cannot validate the network against real outcomes; it is validated against the exact model.
